# Product Design Package

The frozen product specification for Alp-Viram. These documents co-evolve and are
reviewed together. **No technical architecture (ERD, DB, APIs, auth, UI, M1)
begins until this package is approved.**

| 2 | [Product Decision Log](02-product-decision-log.md) | Every major decision: why, alternatives, trade-offs, status. |
| 3 | [Complete User Journey](03-user-journey.md) | Registration → … → Reports, challenging every click. |
| 4 | [Feature Catalogue](04-feature-catalogue.md) | Must / Good-to-Have / Future / Rejected, with reasons. |
| 5 | [Information Architecture](05-information-architecture.md) | The structural model, item types, tags/views, navigation. |
| — | [Architect's Recommendations](06-architects-recommendations.md) | Challenges, risks, simplifications, opportunities, open decisions. |
